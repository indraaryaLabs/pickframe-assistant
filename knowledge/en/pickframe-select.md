## What PickFrame Select is
PickFrame Select is a shortcut for matching local RAW, JPG, and XMP files with the client's selection. PickFrame Select is only a shortcut, so you are free to use other apps or work manually.

## Plans that include PickFrame Select
PickFrame Select is available on the Pro and Studio plans, and during the 24-hour trial. PickFrame Select is not available on the Free plan.

## Starting the work
Photo work starts through PickFrame Select or by hand, whichever you choose.
