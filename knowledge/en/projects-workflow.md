## Start from the project
Record the client and the schedule once, then reopen that project when the photos are ready, the client selection arrives, or a payment comes in. Duration, price, buffer, and working method are set once on each service package.

## Bulk booking
For a quick booking, choose a client. For several sessions at once, paste a list in the format Name, Number, Package, Time. Times can be corrected row by row, and parallel sessions can be flagged when they really are worked at the same time. Bulk booking and reusable client packages are listed as Pro plan features.

## Connecting photos
When using PickFrame Gallery, connect a Google Drive folder from the project. The gallery link, visit status, and client selection appear in the same project.

## Marking work as done
After the results are handed over to the client, mark the project as done. Several projects can be marked done at once, and an Undo button is available. Payment is not a requirement for a project to be done.

## What the side menu does
The Projects menu holds the agenda, the queue, and job details. The Gallery menu is a photo library across projects. The Reports menu holds business figures and access to all documents. The Packages and clients menu stores data you reuse.
