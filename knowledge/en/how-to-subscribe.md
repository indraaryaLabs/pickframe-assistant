## Steps to subscribe
Subscribing takes four steps. First, press the Pesan sekarang (Order now) button on the plan you want, which opens a WhatsApp chat with the PickFrame team. Second, transfer the amount to the account number the team replies with, then send the proof of transfer. Third, receive an activation code shaped like PF-XXXX-XXXX in the same WhatsApp chat. Fourth, redeem that code in the dashboard.

## How to redeem a code
In the dashboard, click the quota marker next to the New project button, paste the code, then press Redeem. The plan becomes active immediately. You can redeem a code yourself at any hour, even at 2 a.m., without waiting for an operator to be online.

## How plans are activated
A plan is activated manually once payment is confirmed, through a code or an operator. Payment is made by bank transfer and confirmed over WhatsApp.

## No automatic renewal
PickFrame has no automatic renewal and stores no cards. A plan stops by itself on its end date, so there is no subscription to cancel.
