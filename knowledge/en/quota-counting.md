## When project and gallery quotas are used
Saving a scheduled session uses one project allowance and no gallery allowance. Connecting a photo folder afterwards uses one gallery allowance. Creating a gallery without a session uses both allowances because the project record is created automatically. Bookings and standalone galleries share the same project quota.

## Does deleting a project give quota back
Deleting a project does not give quota back. A project is counted when it is saved successfully, and retrying a bulk booking is not counted twice. Quota also does not return after data is deleted.

## When quotas reset
Free plan quota resets every Monday at 00:00 WIB. Monthly quota on paid plans resets at the start of the month in WIB. Quota does not accumulate, so unused quota is not carried into the next period. Trial quota is not reset every month.

## How documents are counted
A document is counted when it is issued, not while it is still a draft. Invoice numbers stay sequential per month. Replacing the folder after the client has opened the gallery, or reopening client selection after more than 24 hours, can use gallery quota under the account policy. Changing the link alone does not use quota.
