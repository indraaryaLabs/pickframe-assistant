## Apa itu PickFrame Select
PickFrame Select adalah jalan pintas untuk mencocokkan file RAW, JPG, dan XMP lokal dengan pilihan klien. PickFrame Select hanya jalan pintas, jadi Anda bebas memakai aplikasi lain atau bekerja manual.

## Paket yang mendapat PickFrame Select
PickFrame Select tersedia di paket Pro dan Studio, serta selama trial 24 jam. PickFrame Select tidak tersedia di paket Free.

## Memulai pengerjaan
Pengerjaan foto dimulai lewat PickFrame Select atau dengan cara manual, sesuai pilihan Anda.
