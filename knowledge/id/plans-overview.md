## Tiga paket
PickFrame punya tiga paket: Free, Pro, dan Studio. Paket Free gratis dan tetap aktif dengan satu proyek, satu galeri, dan satu invoice baru setiap minggu. Paket Pro ditujukan untuk fotografer mandiri. Paket Studio ditujukan untuk vendor dan agensi yang menggarap banyak acara sekaligus.

## Perbedaan fitur antar paket
PickFrame Select tersedia di paket Pro, paket Studio, dan selama trial, tetapi tidak di paket Free. Memperbarui buku Excel lama hanya tersedia di paket Studio. Nama studio pada galeri dan dokumen hanya tampil di paket berbayar dan trial.

## Fitur yang ada di semua paket
Semua paket mendapat katalog paket layanan beserta harganya, dashboard pendapatan, tagihan belum dibayar, dan order berjalan, kalender acara, riwayat klien, ekspor buku Excel baru, tiga tampilan workspace, bahasa Indonesia dan Inggris, serta tema terang, gelap, atau sistem. Proyek dan pilihan klien tetap ada saat paket habis.
